## 四、跑起来（安卓真机）

**手机端准备（只需一次）**
1. 设置 → 关于手机 → 连点「版本号」7 次，打开开发者模式
2. 设置 → 开发者选项 → 打开 **USB 调试**
3. 插数据线，手机弹窗选「允许调试」

**电脑端**
```powershell

cd D:\coding\111\smart_hotel_flutter
flutter run                       # 或 flutter build apk --debug 后 adb install
```

只装包不调试：

```powershell
adb install -r build\app\outputs\flutter-apk\app-debug.apk
adb shell am start -n com.smart.smart_hotel/.MainActivity
```

**如果想改回"电脑跑 Node 后端"**（比如对照原版行为）：

```dart
// lib/core/config/app_config.dart
static const ServerMode serverMode = ServerMode.remote;
static const HostEnv env = HostEnv.usbReverse;   // 真机 USB：先 adb reverse tcp:3000 tcp:3000
```

| 模式 | 说明 |
|---|---|
| `embedded`（当前默认） | App 自带后端，127.0.0.1:3000（占用则顺延 3001/3100） |
| `remote` + `usbReverse` | 连电脑 Node 后端，需 `adb reverse tcp:3000 tcp:3000` |
| `remote` + `physicalDevice` | 连电脑内网 IP（本机以太网 `192.168.100.66`），需同一 Wi-Fi 且防火墙放行 3000 |
| `remote` + `androidEmulator` | `http://10.0.2.2:3000` |

## 五、构建时的针对性调整

编译过程中踩到的问题，已在工程里改掉（换机器也建议保留）：

```properties
# android/gradle.properties
org.gradle.jvmargs=-Xmx4G -XX:MaxMetaspaceSize=1G    # 默认 8G，16G 内存的机器会挤爆 Kotlin 守护进程
kotlin.incremental=false                             # 增量缓存文件锁 → "Could not close incremental caches"
kotlin.compiler.execution.strategy=in-process
org.gradle.parallel=false
```

**已移除 `windows/` 目录**，原因有三：
1. 本机没装 Visual Studio，桌面目标本来就编译不了；
2. 留着它 `flutter run` 会误选 Windows 设备，先报 `PathExistsException` 再报工具链缺失，很误导；
3. 桌面目标的插件需要**符号链接**，而本机未开启开发者模式，`flutter test` 会直接报
   `Building with plugins requires symlink support`。

需要恢复桌面目标时：`flutter create --platforms=windows .`（并先装 VS 的 C++ 工作负载 + 开启开发者模式）。

**Android NDK / CMake**：首次 `flutter build apk` 时 Gradle 会自动装（约 1.3 GB），
若被安全软件拦在 `android-sdk\.temp` 写入，先手动 `sdkmanager "ndk;28.2.13676358" "cmake;3.22.1"` 再构建。

## 七、两个必知的坑

1. **`flutter test` 会莫名失败**
   现象：`Unable to connect to flutter_tester process: WebSocketException: Invalid WebSocket upgrade request`
   原因：系统设了 `HTTP_PROXY`，flutter_tester 的本地 WebSocket 被代理拦了。
   解法：

   ```powershell
   $env:HTTP_PROXY=''; $env:HTTPS_PROXY=''; $env:http_proxy=''; $env:https_proxy=''
   $env:NO_PROXY='localhost,127.0.0.1'
   flutter test
   ```

   只跑 `flutter run` / `flutter build` 不受影响。

2. **Gradle 首次构建会自己装 NDK 和 CMake**（约 1.3 GB），耗时 10–20 分钟属正常；
   如果被安全软件拦在 `android-sdk\.temp` 写入，先手动 `sdkmanager "ndk;28.2.13676358" "cmake;3.22.1"` 再构建。

3. **`flutter run` 报 `PathExistsException: Cannot create link ... .plugin_symlinks\jni`**
   原因：`windows\flutter\ephemeral\.plugin_symlinks\` 下残留了**实体目录**（上次构建的复制回退产物），
   Flutter 这次想建符号链接，撞到"文件已存在"（errno 183）。这是 Flutter 在 Windows 上的已知问题。
   解法：

   ```powershell
   cd D:\coding\111\smart_hotel_flutter
   Remove-Item -Recurse -Force windows\flutter\ephemeral
   ```

   已在本机验证：删除后重新生成的是副本目录，构建可正常越过该步骤。

4. **`flutter run` 默认选中 Windows，但报 `Unable to find suitable Visual Studio toolchain`**
   原因：本机没装 Visual Studio，Windows 桌面目标编译不了；而模拟器镜像也没装、手机也没插，
   Flutter 只剩 Windows 这一个"设备"可选。
   解法：插安卓真机（见第四节），或 `flutter run -d <device-id>` 指定设备。
   **这与代码无关**，纯工具链缺失。
